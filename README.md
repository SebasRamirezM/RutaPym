# RutaPyme — Red operativa de entregas

Microproducto para la materia **Matemáticas para la Informática Avanzada** (Equipo 7).
Modela la red de entregas de una pyme como un **grafo dirigido y ponderado** propio,
expuesto mediante una API REST en Python y una interfaz web mínima.

**Equipo:** Emmanuel Cardona · Sebastian Ramirez
